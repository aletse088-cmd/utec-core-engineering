# Python - Estructuras de datos basicas

Proyecto sobre listas y otras estructuras de datos basicas en Python.

## Archivos

| Archivo | Descripcion |
|---------|-------------|
| `print_list_integer.py` | Imprime los enteros de una lista, uno por linea |

## Requisitos

- Ubuntu 20.04 LTS, Python 3.8.x
- Estilo PEP8 (pycodestyle 2.7.x)
- Primera linea: `#!/usr/bin/env python3`
