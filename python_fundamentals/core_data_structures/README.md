# Python - Estructuras de datos basicas

Proyecto sobre listas y otras estructuras de datos basicas en Python.

## Archivos

| Archivo | Descripcion |
|---------|-------------|
| `print_list_integer.py` | Imprime los enteros de una lista, uno por linea |
| `element_at.py` | Devuelve el elemento en un indice o None si es invalido |
| `replace_in_list.py` | Reemplaza un elemento de una lista en un indice valido |
| `update_dictionary.py` | Reemplaza o agrega una clave/valor en un diccionario |
| `print_matrix_integer.py` | Imprime una matriz de enteros, una fila por linea |
| `add_tuple.py` | Suma dos tuplas posicion por posicion |
| `common_elements.py` | Devuelve la interseccion de dos conjuntos |

## Requisitos

- Ubuntu 20.04 LTS, Python 3.8.x
- Estilo PEP8 (pycodestyle 2.7.x)
- Primera linea: `#!/usr/bin/env python3`
