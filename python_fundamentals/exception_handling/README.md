# Exception Handling

This directory contains exercises about handling exceptions in Python.

## Tasks

### 0. Safe list printing
`safe_print_list.py` defines `safe_print_list(my_list=[], x=0)`, which prints
`x` elements of a list on a single line, followed by a new line, and returns
the real number of elements printed. It uses `try/except` and does not use
`len()` or import any module.
