# File Handling

This directory contains exercises about reading and writing files in Python.

## Tasks

### 0. Read file
`read_file.py` defines `read_file(filename="")`, which reads a UTF-8 text
file using the `with` statement and prints its content to stdout.

### 1. Write to a file
`write_file.py` defines `write_file(filename="", text="")`, which writes a
string to a UTF-8 text file (creating or overwriting it) using the `with`
statement and returns the number of characters written.
